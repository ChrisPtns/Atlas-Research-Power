# Ansys Fluent CFD & Hydrodynamics (Lead)

## Στόχοι CFD & Mass Budget
1. **Εβδομάδα 1:** Στήσιμο γεωμετρίας σκάφους/υποβρυχίου στο Ansys Fluent (`fluent_geometry/`).
2. **Εβδομάδα 2:** Πρώτο simulation run στα **2.5 kn** (`simulations/`).
3. **Εβδομάδα 3:** Τελικά διαγράμματα αντίστασης (Total Drag, Friction, Pressure) και άνωσης/βύθισης (`results/`).
4. **Mass Budget (KG):** Συγκεντρωτικός πίνακας βαρών για τον υπολογισμό άνωσης (Buoyancy / Center of Gravity / Center of Buoyancy).
